# Research history

As checked on November 4, 2026, the GitHub repository is public. Historical
references to private drafts describe their delivery at that time. PR #14 is
closed, and its work was superseded by the subsequent consolidation. Current
results include the later subscription follow-up; start with
[paper preparation](../paper-preparation/README.md).

The project grew through separate study branches and review pull requests. They are consolidated in dependency order so readers can use one current branch: `main`.

Original stage tips are preserved as `archive/2026-11-01/...` tags. [Exact commits](branch-snapshots.json) make older states recoverable without keeping every finished remote branch open. Earlier methods, failed attempts, results and reviews are unchanged; the old root README remains frozen for integrity checks.

Stages: pilot → expanded comparison → 761-combination study → controls/source checks → v5/v6 preparation and execution → v7 large study → subscription follow-up → evidence review and figures. The separate overnight research branch is also retained in history.

The consolidation does not make historical claims current. Old access notes, budgets, draft manuscripts and statements that work had not started belong to their recorded stage. Use the current GitHub overview and result READMEs first. The new paper remains unwritten.

Local worktrees are kept because they contain ignored evidence and other work. Their branch names may still appear on the owner's computer after completed remote branches are removed. Do not delete these folders as cosmetic cleanup.

The README-only homepage PR was already merged separately. Earlier stacked PRs are superseded by the checked consolidation, not discarded experiments. New work should use short-lived branches from `main` and pass the relevant offline checks before merging.
