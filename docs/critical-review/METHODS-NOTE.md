# Review methods and closest prior work

Checked November 1, 2026. This is a bounded methodological comparison, not a systematic literature review or manuscript text. Earlier project notes were used to locate sources; claims below were checked against primary pages. No external experiment was rerun.

| Primary source inspected | Relevant overlap | What remains distinct here |
| --- | --- | --- |
| [Passing the Test You Trained On](https://arxiv.org/html/2610.03448), §4 and §5.4 | Task-aware judges and a Sheltron trusted-task variant already exist. Sheltron's AUROC improves while detection at 1% FPR worsens; its task interface is undocumented. | Fixed native interfaces, same candidate bytes, empty-field/reminder/character-filler controls and preserved first failures. Do not claim task sensitivity or error tradeoffs were first discovered here. |
| [Robust Context-Aware Detection of Malicious Instructions in Text (CAD)](https://arxiv.org/html/2608.05430), §3 and Appendix B | A trained sentence filter uses query and surrounding response; its ablation removes the query. Agent-level security and utility move differently. | This study changes input information for fixed whole-page classifiers without retraining. Static classification is a different endpoint from CAD's downstream utility/attack success. |
| [The Task Shield](https://aclanthology.org/2025.acl-long.1435.pdf), §§3, 5.3 and Table 3 | Runtime task-alignment checks and goal-restatement ablations precede this work. | A multi-call enforcement system differs from a static detector. The present 12-case pilot cannot support equivalent defense-efficacy claims. |
| [AlignSentinel](https://arxiv.org/html/2602.13597v2), §§3–4 | Explicit aligned/misaligned/non-instruction classes, conditioned on higher-priority task instructions, using attention features. | No new classifier or task-relative label ontology is developed here. The contribution is an empirical controlled comparison of frozen configurations. |
| [BrowseSafe++](https://arxiv.org/html/2610.17457), §2.2 and Appendix C.2 | Publisher pairs use selected injections and privacy-rewritten surrounding pages. Its detector setup withholds tasks, limits Markdown to 40,000 characters, and has its own output/coverage rules. | This project uses a grouped, project-held-out subset of the released **training** collection and complete Markdown. Published test scores are not directly comparable and its trained guard is not an unexposed baseline. |

The plausible contribution is a careful replication/extension: whether revealing the publisher task improves agreement with fixed source labels beyond several prompt controls, with source-specific error tradeoffs and explicit missingness. This could sustain a focused five-page empirical report. It does not establish venue acceptance or exhaustive novelty; no additional paper count is needed.

The requested scientific-critical-thinking v1.5, experimental-design v1.5 and statistical-power v1.3 skills informed unit definitions, paired comparisons, precision and claim limits. No clinical quality score, post hoc observed power or new experiment design was imposed.
