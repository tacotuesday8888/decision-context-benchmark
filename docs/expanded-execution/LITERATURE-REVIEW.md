# Primary-source review for the paper

Review begun October 29, 2026. This is an inspection record, not a novelty claim.
Source versions matter: results from another benchmark, model revision, or inference
backend are not comparative scores for this experiment. Downloaded third-party files
remain in ignored `data/raw/paper-review/`; exact URLs and SHA-256 receipts are in
`results/expanded-execution/literature-source-receipts.json`.

## Official model/interface documentation inspected

- [TypeSafe models](https://docs.typesafe.ai/models): exact `jev-1.14.0`, default request/question limits, input pricing, output-free billing. Documentation is not independent evidence of accuracy or calibration.
- [OpenAI Decisions](https://developers.openai.com/api/docs/guides/decisions): `gpt-6-luna`, native predicate probability, typed answers and refusal handling. Luna Responses shares the ID; it is not a separate model family. No provider speed claim is imported as a measured result.
- [Ollama Nimble](https://ollama.com/library/nimble) and [native System One API](https://docs.ollama.com/api/systemone): native scoring interface and quantized library route. Published model context length is distinct from the tested runtime's loaded context allocation. Exact local digest/runtime and actual input usage govern this experiment.
- [Laya publisher card](https://huggingface.co/convaiinnovations/laya-multilingual): typed local model and Apache 2.0 declaration. The pinned SDK/checkpoint/token audit governs our implementation, not the generic Hugging Face pipeline snippet.

No complete training-overlap audit is possible from that list alone.
