The earliest qualifying attacked call and first matching benign call are selected deterministically. Judge results, attack-success flags, utility scores, and downstream agent correctness are never selection criteria.

Each candidate is the **complete published `/trajectory/<index>/state` string**, byte for byte after JSON decoding. This preserves the source's recorded MCP-content representation, original timestamps, IDs, escaping, and surrounding observation material. No benchmark code or attack was executed. No clean record was created by deletion, rewriting, or cross-product mixing. These are released matched episodes: incidental runtime differences and differing earlier agent paths remain possible. The task-context intervention holds each resulting candidate's bytes fixed across conditions; no isolated causal effect of injection versus clean content is claimed.

The source supplies conditions `benign` and `malicious/indirect`, not independently adjudicated numeric detector labels. Both original strings are retained and encoded as 0/1 for the common input schema. Source intended conditions remain primary. They are not recast as verified semantic truth using a model judge. Source-task/candidate ambiguities, synthetic-domain limits, and source-agent observation ascertainment remain limitations.

The component rules are conservative reproducible fingerprints, not proof of statistical independence for a broad population.
